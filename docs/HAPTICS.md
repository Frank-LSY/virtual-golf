# 手机震动（0.26.0）

所有手机控制器（高尔夫球杆、云端滚球手柄、体感钓鱼鱼竿）共用一套“触感语言”，代码在 `phone-web/haptics.js`。

## 规则

- **一个信号一个名字**：例如 `impact`（计杆击球）、`bite`（咬钩）、`wall`（撞墙）、`turn`（轮到你）。同一类信号手感一致，不同信号的节奏、段数明显不同，不用看屏幕也能分辨。
- **优先级 0–5**：正在震重要信号（例如咬钩、坠落）时，次要信号（按键轻触、刻度）直接跳过；同级或更高的信号会打断当前震动。
- **限频**：每个信号有最短间隔，连续撞墙、张力危险不会震成一片。
- **强度**：关闭 / 轻（×0.65）/ 标准 / 强（×1.5），只缩放“震”的时长，停顿不变，节奏保持可辨；“按键轻触”可以单独关掉。设置保存在这台手机上（`swinglink-haptics`），三个控制器的设置面板实时同步。
- **安卓 Chrome 等**：支持 `navigator.vibrate`，全部信号可用。浏览器要求页面先被点过一次才允许震动（打开页面后点“启用体感 / 加入”就满足）。
- **iPhone Safari**：没有网页震动接口。用系统开关控件（`<input type="checkbox" switch>`）的触感兜底，iOS 18.4 起只在点按后约 1 秒内生效，所以 iPhone 上主要是**按键和点按触发的轻触**，比赛中的事件信号仍靠画面和声音。需要“设置 › 声音与触感 › 系统触感反馈”打开。
- **不干扰识别**：震动都很短（单段 ≤ 0.2 秒）；采集训练数据时只在“请挥杆”前提示一下，录制中不震。

## 事件从哪里来

- **高尔夫**：手机本地识别挥杆（击球 / 试挥）；服务器的 `room_state`（准备、球停稳后最后一杆是不是自己的、进洞 / 罚杆、进入下一洞）与 `round_subscription`（开局、轮到你）。
- **云端滚球**：碰撞类事件在电脑上的物理里产生，电脑发 `maze_feel {events:[{kind, strength, slot?}]}`，网关只转给对应手机（单人：当前手柄；对战：该位置的手机，碰球两边都发）。倒计时、出发、赛段、崩塌距离、出局、名次由手机按 `maze_versus_state` / `maze_game_state` 的变化判断。
- **体感钓鱼**：网关发给每台手机的个人事件（咬钩、刺中、冲刺……）和比赛事件（倒计时、开钓、时间到）；收线棘轮、张力心跳、松线提醒按 `fish_personal` 里的距离 / 张力 / 松线量判断。
