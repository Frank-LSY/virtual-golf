# 八卦重力滚球

分支：`feat/rabbitzzc/bagua-maze`。这是同一个本地平台里的独立游戏入口，不依赖挥杆模型或个人力量标尺。

## 怎么玩

运行 `npm start`，打开 `http://localhost:5173/#maze`，也可以点击顶部「八卦滚球」Tab；已有高尔夫球局中可通过「☯ 滚球」进入，再切回原球局。

- 电脑：方向键 / WASD 控制加速度，松开会滑行，反向操作可以刹车。P / Esc 暂停。
- 手机：电脑点击「连接手机」，两台设备连接同一网络，打开二维码中的 HTTPS 地址。电脑切到滚球后，被选中的手机自动进入手柄界面，不需要单独配对另一套连接。
- 手机点击「启用倾斜控制」，保持自然握姿静止约 0.6 秒。横向端住手机，左右、前后轻轻倾斜；横屏两个方向、竖屏都有坐标转换。换屏幕方向会重新归零并暂停，准备好后手动继续。
- 没有传感器、拒绝权限、HTTPS 未就绪时，可以直接选择「虚拟摇杆」。拖动控制加速度，松手归零；物理与倾斜、键盘相同。
- 顶部显示关卡，侧边显示本次用时和落洞次数。第一次有效操作才计时；手机也可以暂停、继续、重试和进入下一关。
- 暂停或切走页面后时间和运动冻结；恢复有 1 秒准备时间并清零速度。落洞有短暂缩小反馈，复活清零速度、保留累计用时和落洞次数；手动重新挑战才清零本次记录。
- 中心浅色太极图是终点，深色洞口是陷阱。进入中心有效区域后，速度低于 22 单位/秒并停留 0.75 秒才通关，高速掠过不算成功。

## 三关与路线

| 关卡 | 训练目标 | 路线与风险 |
| --- | --- | --- |
| 初见 | 加速、回正滑行、转弯前减速 | 三层环墙，宽缺口错开，无陷阱；需要逐层绕行。 |
| 知止 | 缺口前刹车、通过后重新加速 | 四层环墙；第二道环墙右下 48° 入口较近，出口附近有洞，左下 145° 绕得远、容易稳住。第一道入口后也要提前制动。 |
| 观势 | 看下一环、选择路线、改变绕行方向 | 五层环墙；右侧 10° 近路经过洞口，左侧 165° 路线更长；三处径向隔断要求按下一道缺口规划，最后两层要改变绕行方向。左侧有无陷阱的观察缓冲段。 |

所有关卡和陷阱固定，不使用随机漂移或自动寻路。陷阱按球心进入洞内有效半径判定，视觉上擦过洞缘不会立刻失败。声音默认关闭，可单独开启简短碰撞、落洞和通关声。

## 模块与参数

- `shared/maze/levels.js`：关卡和精确圆弧、径向墙几何，绘制、碰撞和测试共用。
- `shared/maze/physics.js`：不访问 DOM 或网络的运动核心。120Hz 固定步长、速度限制、摩擦、惯性、圆弧/端帽/线段碰撞、落洞、暂停和通关判定。
- `shared/maze/tilt.js`：与游戏分离的屏幕坐标转换、稳定握姿归零、90ms 低通、1.5° 死区、18° 满量程和向量限幅。仅识别倾斜量，不估算玩家能力。
- `local-gateway/maze-channel.js`：复用既有 WebSocket、手机身份和二维码，隔离 `maze_*` 消息；单电脑窗口拥有盘面、显式选择手柄、序号去重、约 30Hz 输入、550ms 断流暂停和断线暂停。
- `screen-web/maze*.js` / `maze.css`：独立 Canvas 盘面、游戏流程、键盘控制与展示。球场、计分和高尔夫物理沿用现有实现。
- `phone-web/maze-controller.js` / `maze-entry.js` / `maze.css`：复用原手机连接；传感器权限、连续倾斜、虚拟摇杆、常亮与后台保护。进入滚球时原高尔夫动作处理暂停，退出后恢复。

优先使用设备姿态事件估计重力方向，缺失时使用含重力加速度；坐标系按 [W3C Device Orientation and Motion](https://www.w3.org/TR/orientation-event/) 转换。传感器权限和 HTTPS 仍受浏览器限制。

## 验证

```sh
npm test
npm run test:maze
npm run test:integration
npm run test:courses
npm run test:multiplayer
npm run test:ml
```

自动测试覆盖：三关以加速度输入真实模拟通关（不瞬移球）、两条分支均可达且路程不同、30/60/120Hz 一致性、反向制动、墙体不穿透、沿墙移动、陷阱擦边与复活、暂停/恢复/重试、终点低速停留、横竖屏坐标、校准与断流、权限拒绝与摇杆替代、手机和高尔夫输入隔离，以及真实 WebSocket 下的选机、独占、状态同步和失联保护。路线搜索仅在测试中使用，不进入游戏。

本地浏览器已实际操作电脑键盘与手机网页摇杆，确认手机输入启动电脑端计时，手机暂停、继续、重试和桌面切换有效，并检查手机横屏、竖屏布局。

仍需实体手机验收：iPhone Safari 权限弹窗、正反横屏实际倾斜方向、不同自然握姿的舒适度、网络延迟与真实手抖。模拟数据和网页摇杆不能替代真机手感验证。目前滚球记录仅保留在该电脑页面的本次会话，刷新页面会重置；没有新增依赖或云服务。
