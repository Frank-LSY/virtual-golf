# 云端滚球 · SKYROLL

本分支将原圆盘玩法替换为第三人称 3D 悬空赛道。保留高尔夫、手机身份、二维码、传感器权限和独立 `maze_*` 连接协议；模块文件路径沿用 `maze`，不代表仍有圆盘迷宫。

## 启动与控制

```sh
npm start
```

电脑打开 `http://localhost:5173/#maze`，或点击顶部「云端滚球」Tab。原高尔夫球局中也可通过「滚球」按钮切换，切回后保留球局状态。

- 电脑：方向键 / WASD 控制当前镜头方向上的加速度；↑ / W 前进，↓ / S 先刹车再后退。P / Esc 暂停。
- 手机：同一网络下扫描现有「连接手机」二维码；电脑切入滚球时，所选手机自动显示滚球手柄。选择「启用倾斜控制」，自然握持静止约 0.6 秒。远端压低前进，近端压低刹车或后退，左右轻倾控制横向加速度。
- 无传感器或未获权限时，手机可以选择虚拟摇杆；三个输入方式使用同一套物理。
- 手机支持横屏两侧及竖屏。屏幕方向变化会撤销就绪、重新归零并暂停；恢复后需手动继续。
- 手机上的倾斜控制需要受信任的 HTTPS，现有「连接手机」面板保留证书设置说明。摇杆和电脑键盘不依赖传感器。
- 通过「手柄设置」可换控制方式、选择手机和重新归零。打开设置暂停当前挑战。

## 三关

| 关卡 | 内容 | 练习与策略 |
| --- | --- | --- |
| 初航 | 7 米宽主路、缓坡、两个转弯、短无护栏路段 | 学会惯性与反向刹车，转弯前减速；宽平台和护栏提供练习余量。 |
| 逐风 | 上下坡、横移挡块、3.4 米窄桥 | 挡块前停球观察，下坡先刹车；桥头、桥后设置检查点。 |
| 云岔 | 近路与稳路分叉并汇合，最后组合转弯与移动挡块 | 直行近路宽 2.6 米、没有护栏；左转稳路宽 7.2 米，多绕约 48 米，有护栏、缓坡和一个较慢挡块。两条分支均能通关。 |

黄色环标记检查点，激活后变绿；HUD 的 `C1`、`C2` 等表示当前复活点编号。分支检查点可跳过，不要求收集全部编号。安全平台可以停球看路。终点为赛道末端的绿色圆区和 FINISH 门架，低速进入有效范围并停留 0.65 秒才通关。

第一次有效操作才开始计时；坠落累计次数并计入用时。离开无护栏道路后有真实的重力下落，约 1 秒后回到最近激活检查点，清零速度并准备 1.1 秒。手动重新挑战会清空本次用时、坠落、检查点和速度。

暂停同时冻结球、移动障碍和计时。电脑失焦、页面进入后台、手机切后台、断线或输入断流都会暂停。恢复连接不会自动继续。多个电脑窗口可以明确点击「使用这个窗口」接管，原窗口会暂停，关卡进度保留在各自页面。

## 运动、镜头与工程边界

- `shared/maze/levels.js`：固定赛道、平台、缓坡、护栏裁剪、检查点、终点和横移障碍。画面和碰撞共用几何；交叉连接处移除内部护栏。
- `shared/maze/physics.js`：纯运动核心，120Hz 固定步长。包含加速度、惯性、摩擦、限速、坡向重力、护栏胶囊与移动 OBB 碰撞、坠落、复活、计时和通关。
- `shared/maze/camera.js` 与运动核心共用朝向；镜头沿当前道路方向平滑转向，有最大角速度；短暂后退不翻转。控制向量按同一个镜头水平朝向转换，避免物理与画面使用不同方向。镜头保持球后上方、前看，并检测赛道遮挡；复活时重设镜头。
- `screen-web/maze-renderer.js`：沿用现有 Three.js，独立绘制天空、浮岛、实体道路、彩色护栏、滚动小球、障碍和终点。第一次进入时才创建 WebGL 场景，切关释放旧赛道的几何、材质和标签贴图。
- `screen-web/maze.js`：游戏流程、键盘、HUD、手柄设置、事件反馈。高尔夫场景与计分规则不变。
- `shared/maze/tilt.js` 和 `phone-web/maze-controller.js`：复用静止归零、90ms 低通、1.5° 死区、18° 满量程、横竖屏转换与摇杆；不把倾斜送入高尔夫模型。
- `local-gateway/maze-channel.js`：复用现有 WebSocket，增加检查点状态同步，继续提供独占、显式选机、序号去重、约 30Hz 输入和断流保护。

没有新增依赖、外部图片、云服务、付费系统或通用游戏框架。赛道和球体材质由代码生成。

### 机关（`shared/maze/levels.js` 定义，`shared/maze/physics.js` 计算）

- **加速带** `boost(id, roadId, t0, t1, power)`：铺在道路 t0–t1 段，沿道路方向额外加速度 15–16 m/s²；在上面及离开后 1.2 秒内速度上限从 7.2 提高到 11 m/s，之后以 5 m/s² 平滑回落。
- **弹射柱** `bumper(id, x, z, y, radius)`：静止圆柱，碰撞后沿法线的离开速度至少 5.5 m/s。
- **旋转风车** `sweeper(id, x, z, y, length, speed, phase, arms)`：立柱 + 绕立柱转动的胶囊横杆（单臂或双臂），接触点速度 = 角速度 × 半径；被扫到时相对横杆的离开速度至少 2.6 m/s。平台角落在横杆够不着的范围外。
- **往返浮台** `mover(id, a, b, y, hx, hz, period, phase)`：在 a、b 两个停靠位置之间往返，两端各停 20% 周期，中间平滑加减速；球站在上面时按浮台每步的位移被带走（不受浮台加减速影响）。停靠位置会自动在岸边护栏上留出开口。
- **路面** `surface: 'ice' | 'fluff'`：冰面加速度 ×0.38、空气阻力 ×0.16、滚动阻力 ×0.1，松手不会自动停住；云絮空气阻力 ×3.4、滚动阻力 ×3。
- 新事件：`boost`、`bump`、`sweep`、`board`，供音效与画面使用。

### 星级与纪录

- 3 星：不坠落且不超过标准用时；2 星：坠落不超过 2 次且不超过标准用时的 1.6 倍；完成即 1 星。
- 纪录（最佳用时、星级、通关次数）保存在电脑浏览器的 `swinglink-skyroll-records`；地图页显示总星数、每章星数、每张最佳用时和“下一张”。
- 标准用时来自自动测试：测试控制器只用加速度驾驶（巡航 2.4 m/s，遇到风车 / 挡块先停住等“预测接下来几段路线不会被碰到”的时机，遇到浮台等靠岸再上），最短路线不超过标准用时，绕行路线不超过 1.6 倍。
