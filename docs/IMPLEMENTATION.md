# 实现与验证记录

## 已实现的本地功能

- 晴空公园、海岸林克斯、山谷松林，每套 9 洞；支持 3 洞和 9 洞。
- 连续三维高度场地形、球道、长草、果岭、沙坑、水、树木、岩石、旗杆、球与镜头动画。
- 服务端与渲染使用相同球场数据；每洞风况在击球前确定。
- 固定步长的飞行、弹跳、滚动、坡度、树干碰撞、低速进洞、落水/出界处罚与 12 杆上限。
- 自动选杆、瞄准、键盘蓄力、路线图、相对风向、距离、果岭网格和成绩卡。
- 本地 HTTP/HTTPS、二维码配对、消息校验、序号去重、输入锁定、心跳、重连与存档。
- iPhone 权限、分步握姿归零、自动找轴、轻/舒适挥幅采样、两次复测、校准复用、状态机、冷却、常亮与中断提示。
- 挥杆练习室、调参、最近 50 条记录、手感标记、漏识别标记、中文 JSON/CSV 导出。

## 中文版与 Mac 版

0.2.0 将电脑界面、手机界面、三套球场及 27 个球洞、球杆、计分反馈、错误提示、辅助功能标签、启动提示、日志导出和使用说明改为中文，并补充中英文系统字体回退与中文排版。

Mac 启动包分别面向 Apple 芯片和 Intel，内置 Node.js 22.23.4 对应的官方二进制与运行依赖，提供双击启动、浏览器自动打开及手机连接配置。证书扩展改用配置文件以兼容 Mac 的 LibreSSL，不依赖 -addext。打包时排除证书、私钥、配对令牌和现有存档。

协议字段、代码标识符、软件产品名与第三方许可证保留原有名称，以维持兼容性和许可文本的准确性。

## 0.6.0 多人及引导校准

支持明确选择 2–16 人并勾选对应手机。服务端按稳定手机身份校验控制权；每杆轮换、独立球位/瞄准/杆数/罚杆/成绩，全部完成后再推进球洞。断线取消准备但保留球手，不自动切换到其他手机。多手机配色与姓名在 3D 画面及记分卡中显示；人数较多时名单可横向滚动。

训练状态按手机隔离并持久化，切换手机清除未应用草稿。校准采用明确的一次动作采样、三轴能量判断、轻挥/舒适挥幅分离、两次 50% 目标带复测。错误动作、混合轴、相近力度、握姿偏转、断流、切后台均有具体反馈。确认后才使用新结果；支持仅重置握姿。

35 组自动测试通过，包含实际手机控制器的完整校准流程、同伴校准消息不打断当前动作、2/3/4/6/8/16 人轮次、独立记录、控制权及断线恢复。HTTP/HTTPS/单手机集成测试通过。独立多手机 WebSocket 集成测试涵盖双手机完整击球、独立调参和校准请求、记录落盘与归档、重复身份替换，以及 3/4/6/16 人建局和人数不符拒绝。

浏览器使用两个不同本机地址的独立手机页面，检查身份/昵称、名单选择、第三人称双球手、当前控制提示、练习室选择手机与定向校准请求。没有真实运动传感器，完整动作由模拟事件验证。手机实机、16 台实体设备同时连接和 Mac 真机性能仍待验证。校准设计参考 https://www.nintendo.com/jp/ichikara/as8sa/index_en.html ，没有真实手感优于 Nintendo Switch Sports 的对照结论。

Mac 0.6.0 Apple 芯片和 Intel 包按当前源文件生成，使用既有打包器进行完整性、架构、脚本执行权限、源文件一致性和私钥隔离校验。

## 已完成的验证

0.5.0 将正式球局改为第三人称：共用原创球手和装扮，增加试挥、单杆准备、挥杆动画、追球、落点停留及球手移位。人物站位以球坐标、朝向与地形高度计算，自动使用当前位置对应球杆；处罚后回到有效球位。正式球局试挥不修改杆数、球位、成绩或存档版本，准备后的有效挥杆才计入成绩。存档恢复不保留准备状态。

正式球局和练习室现在都在试挥、已准备时持续响应手机陀螺仪：上杆 / 下挥驱动人物，三轴角速度驱动有限角度的平滑观察视角；观察方向不改变权威瞄准角。断流后归中，重新校准、手机离线、切后台和切换场景会取消准备。追球及球手移位期间以自动镜头为主。传感器仅向正在观看对应场景的电脑转发，不保存原始流。

0.5.0 验证：25 组自动测试通过，覆盖正式试挥不计杆、一次准备一杆、错误输入不消费准备、手机在两种准备状态下持续传感、切后台取消准备、视角限幅 / 平滑 / 断流归中，以及站位跟随球坐标和地形。本地 HTTP / HTTPS / WebSocket 集成测试通过，包含正式试挥、手机准备、实际击球、传感转发和重连存档。

浏览器实测：正式球局试挥后球与杆数不变；铁杆击球后人物来到长草区、自动换劈起杆；第二杆后移到果岭、自动换推杆；第三杆推球入洞，计分卡显示标准杆并可进入下一洞。电脑和手机真实体感联动仍未通过实体 iPhone 验证，陀螺仪联动以实际控制器代码的模拟事件、通道测试及镜头算法测试验证。窄屏及 Mac 真机边界同下文。截图见 screenshots/round-third-person-zh.png。

0.5.0 的 Mac Apple 芯片与 Intel 包已按新版源文件重新生成，完成架构、执行权限、完整内容与私钥隔离等静态校验。

0.4.0 将挥杆练习室升级为第三人称场景：新增原创程序化球手、三套装扮、上杆 / 下挥 / 收杆关节动画、第三人称站位、俯视和追球镜头、自动回位、左右瞄准、力量条与真实模拟刻度小地图。手机动作驱动人物姿态；完整传感器与调参面板可展开。正式球局保留原有镜头。

交互改为“试挥 → 准备一杆 → 击球 → 观察落点 → 回到试挥”。准备状态由服务器同步到电脑与手机，试挥不改动历史，实际击球自动解除准备。断开手机、重新校准、手机切到后台或关闭全部练习室会取消准备。训练出界反馈保留实际轨迹终点，正式球局出界处罚不变。

0.4.0 验证：20 组自动测试通过，新增单杆准备、试挥隔离、重新校准取消准备、瞄准角度、力量地图与物理结果一致、训练边界反馈测试。手机控制器测试使用模拟事件确认准备按钮、实际挥杆及试挥回执。真实本地 HTTP / HTTPS / WebSocket 集成测试通过，覆盖校准、传感器、调参回执、训练击球、正式球局、重连及存档。

浏览器已检查第三人称渲染、装扮切换、俯视切换、完整试挥与击球流程、左右瞄准、空格击球、取消准备、传感器面板展开、历史反馈和手机入口。桌面宽度下无横向溢出；调整后左侧三轴读数与底部操作栏不重叠。电脑与手机入口均未记录运行错误。实际截图见 screenshots/training-third-person-zh.png。窄屏样式已补充，预览工具未应用指定窄屏尺寸，仍不记为手机真机视觉验证。

0.4.0 的 Mac Apple 芯片与 Intel 包均重新生成并完成下述静态验证；没有实体 Mac 或 iPhone 测试结果。

0.3.0 新增独立训练场、球杆动作示意、三轴传感器流、双端灵敏度同步与回执、四种训练球杆、目标距离、模拟击球反馈、节奏测量、历史回看和中文训练导出。训练状态与正式球局隔离；原始传感器流仅转发给正在观看练习室的电脑，不写入磁盘。灵敏度在手机保存，训练记录在服务器内存保留最近 50 杆。

训练版验证：17 组自动测试通过，包括四种球杆的飞行 / 滚动测量、左右对称偏差、重复和忙碌输入拒绝、参数范围、灵敏度单调映射、节奏测量、订阅隔离，以及实际手机控制器代码的校准 → 体感 → 反馈流程（使用模拟传感器事件）。本地连接测试验证真实 WebSocket 上的传感器转发、手机参数回执、练习弹道、重复拒绝和正式球局恢复。

浏览器已验证电脑铁杆和推杆试打、目标切换、手机参数确认、手机诊断页面和页面运行无错误。当前训练页在默认桌面宽度下无横向溢出；已实现窄屏重排样式，但本次预览工具未实际应用指定窄屏尺寸，因此不将窄屏视觉检查记为通过。此限制与原有 0.2.0 手机页验证分别记录。

中文版最终验证：11 组自动测试通过，包含旧版记录到中文 JSON/CSV 的兼容性。中文界面的开球反馈、配对步骤与证书名称已在浏览器确认；手机页面在 390 × 844 尺寸下无横向溢出。

- 规则测试：27 洞数据、三档力量下的有限轨迹、确定性、20 次连续挥杆、抖动与中断拒绝、力量映射、风向效果、推杆不受风、快慢进洞、处罚、重复/过期输入、锁定、存档恢复以及实际短推完成 9 洞。
- 本地集成测试：静态资源、私有文件阻断、明确指定根证书的 HTTPS 校验、配对认证、手机校准、练习反馈、权威击球、重复输入、重连、解锁、断连与保存。
- 前版浏览器实测：开球、攻果岭、推杆三杆完成一个三杆洞，计分卡正确，进入下一洞，刷新后恢复球位和杆数。
- Mac 包静态验证：官方下载 SHA-256、Mach-O 二进制架构、可执行权限、中文文件名、Unix 换行、压缩包完整性、源文件一致性和私钥隔离。

## 尚未验证与后续范围

当前开发设备为 Windows，没有实体 Mac 与 iPhone 的执行结果。Mac 真机双击启动、系统安全提示、证书安装、iOS 权限、常亮和体感手感仍需在目标设备上验证。打包成功不代表已完成 Mac 真机测试。

传感器默认主轴、轻中重区分、误触率、方向零点和推杆手感需真实试挥。程序生成内容仍需人工评估难度和平衡。公网双人联机不属于本次本地版范围。

原文档的 M0 输入验收仍是下一步真实设备测试关卡；现有自动测试不能替代主观手感验收。
