# 挥杆之间（SwingLink）

中文本地三维高尔夫：电脑显示球场，iPhone 充当体感球杆。当前版本为 **0.13.0，六座九洞球场与球车接驳版（本地 2–16 人可选）**。

## 本次更新：球杆声音、空间感与原创贴图

- 挥杆练习室改为田径场风格：中央草坪、八道环形跑道、分道线、看台、雨棚、灯杆和距离标记。移除练习室树木、山丘与海面，保留试挥、准备、追球与手机独立训练。跑道是适配长距离击球的场景布局，不宣称标准 400 米田径场尺寸。
- 正式球场使用有随机高低、宽窄、旋转与偏斜的多面树冠，阔叶树七组叶团、松树五层枝叶；显示与碰撞共用轮廓。长草改为四款透明草簇，近处保留立体交错与风摆，远处逐渐收起。
- 高尔夫球保留真实凹点几何，增加细微球皮纹理、短瞄准线与涂层高光。几何和纹理跨球洞复用，减少重复生成开销。

- 六类球杆具有独立触球声：木杆厚实、铁杆清脆、推杆轻敲；沙坑增加颗粒摩擦，长草带出草叶声，球道与果岭落地声音也有区别。声音力度随实际击球力度和碰撞速度变化。
- 音量和左右声道依据真实镜头位置、朝向与接触点计算，远处和背后的声音更轻、更柔和；旋转、缩放和追球时持续平滑更新。沿用上一版音乐避让与简洁控制面板。
- 原创素材覆盖天空、透明云朵、树皮、阔叶、松针、沙地、水面、球道、长草与果岭。近景增加细节和轻微凹凸，远景逐渐淡化；保留树木碰撞、水花和地形物理。
- 新增贴图仅约 **689 KB**，采用四张共享 WebP、版本化缓存与批量云层绘制；不向手机传输贴图或音频采样。远处草叶收起，空间声音最多同时保留 12 组，结束后回收。

## 风声、鸟鸣与音乐避让

- 增加随球场风力变化的柔和风声，以及间歇、带左右空间感的鸟鸣；顶栏扬声器按钮统一控制球场环境音和击球音效。
- 正式击球后，背景音乐自动降低；撞树、落杯时进一步降低，球停稳后约两秒平滑恢复。练习室同样适用，试挥不触发音乐避让。击球期间环境音也减弱，让反馈更清晰。
- 使用更新后的 Butterfly Waltz 音频。顶栏只显示音乐开／关，点击后仅有播放／暂停和音量调节；自动降低不改变保存的音量，也不会重新播放已暂停的音乐。

## 沙坑与长草

- 沙坑增加浅凹地形、细沙和耙纹；落球与救球时扬起沙粒，球停稳后轻微陷入沙中。球位近景使用精细地面，显示高度与物理判定一致。
- 长草增加立体草丛、风摆和击球扰动；草叶会降低出球速度、吸收落地冲击并缩短滚动。
- 地形提示显示当前球位、相对球道的出球速度和滚动特征；换杆即更新，手机也显示提示。沙坑杆比推杆更适合沙地救球。这里的百分比比较同一球杆、同一力度的模拟出球速度，不代表距离比例。
- 陷沙深度随每位球手的球位保存，轮换和重连不丢失；中文记录增加地形、出球速度、飞行/滚动距离和陷沙深度。

## 上一版：撞树与落水

- 树干与树冠共用三维模型和碰撞面，连续检测高速球，修复从树冠和细树干穿过的问题。
- 树干按接触角度反弹，树冠柔性阻挡并减速；加入枝叶晃动、碎叶、木屑及不同碰撞音效。
- 球接触实际水面时喷溅，涟漪扩散并下沉；近景从水面侧观察，避免停放球车挡住画面。彩虹拖尾在水面停止并淡出。
- 干燥岸坡不再误判落水；水覆盖沙坑时以水面为准。沿用落水加罚一杆、返回原球位的本地游戏规则，碰撞记录归属当前球手并可中文导出。

## Windows 快速启动

双击根目录的 **启动挥杆之间.cmd**。电脑需安装 Node.js 20 或更新版本；依赖缺失时会自动安装。游戏启动后自动打开浏览器，保留终端窗口即可继续游玩。按 Ctrl+C 停止。

也可以在项目目录执行：

```powershell
npm ci
npm start
```

打开 **http://localhost:5173**。

## 怎么玩

选择苹果园九洞、晴空公园、山谷松林、赤岩绿洲、海岸林克斯或雨林云谷。六座完整球场共有 54 洞，难度由 1 至 6 级递进；默认 9 洞完整局，也保留 3 洞快速局。每洞提供打法建议和难度标记。

大厅和正式球局都有“九洞全场导览”，可查看九洞空间布局、球车路线、难度节奏和参考来源，并支持缩放、旋转、平移与逐洞查看。完成本洞后点击“乘球车前往下一洞”，所有球手一起接驳，到站后再选杆和准备。可点击“直接到站”跳过剩余动画；完成整轮可乘车返回会所。多人身份与个人计分保持独立。详见 [球场设计与资料来源](docs/COURSE-DESIGN.md)。

- **试挥与准备**：正式球局默认试挥，人物做动作、显示模拟距离，但球位和杆数不变。点击电脑或手机的“准备击球”，下一次有效挥杆才出球并计杆，之后自动回到试挥。
- **电脑操作**：调整方向和力量，点击“试挥一次”或准备后的“按此力度击球”；也可按住空格蓄力、松开执行当前模式。
- **手机操作**：完成连接和校准后，横握手机上杆、下挥。电脑上的方向滑块与手机相对倾斜共同决定出球方向。
- **每杆自主选杆**：电脑与当前球手的手机都可选一号木杆、7 号铁杆、挖起杆、沙坑杆、劈起杆或推杆，也可接受按球位推荐。换杆会取消准备，需要重新试挥或准备；实际球杆与选杆方式写入本杆记录。击球后下一杆重新推荐。
- **不同球杆的贴图与造型**：分别使用碳纤维、拉丝精钢、香槟镍色、铜色喷砂、枪灰金属和带白色瞄准线的哑黑杆头。握把、杆身、沟槽分开建模；点击“球杆细节”可旋转、缩放杆头特写或查看整杆，直接选用。练习室同样支持六类球杆。
- **第三人称球手**：正式球局沿用练习室的原创人物与四套装扮。人物上杆、下挥、收杆，出球后镜头追球，落点确认后，18 米以内交替迈步、摆臂走到新球位，超过 18 米由球车接送，依次上车、行驶、下车，再推荐下一杆；落水和出界则返回处罚后的有效球位。
- **手机视角**：试挥和已准备状态下，轻转手机都能调整人物观察视角，人物也随动作摆杆。视角采用平滑与限幅，静止时缓慢回中，断流后归中。出球和移动期间追球镜头优先，下一球位继续响应体感。视角观察不会改变电脑瞄准角；手机握姿偏转仍按原规则影响出球方向。
- **彩虹轨迹**：正式球局和练习室都有彩虹拖尾、描边与柔光；随球逐段显示，到位后渐隐。推杆光带更细，进洞后隐藏，避免遮挡球和洞杯。
- **移动与轮换**：球车导航避开水面、边界和树干，行驶时间压缩以减少等待。找不到通行路线时回退到步行。球手移动结束后才解除击球锁定，多人模式随后切换下一位。进洞和原地处罚不安排无效接送。
- **观察球场**：“查看果岭坡度”显示实际地形网格；“球道俯视 / 人物视角”切换镜头；“视角归中”恢复默认观察方向，拖动场景也可环顾。路线图支持拖动平移、滚轮 / 双指缩放、按钮 / 双指旋转；俯视支持拖动旋转、改变俯角和缩放，均可复位。“洞杯特写”可近看洞口。
- **球与洞杯**：球使用真实网格凹点，飞行与静止保持一致比例，并随移动滚动；洞杯有开孔、内壁和洞底。低速进洞会先进入洞缘，再下落到洞底，镜头自动切近；高速擦边不会吸入。尺寸和弹道仍为易于游玩的游戏模拟。
- **基本规则**：风只影响飞行。长草、沙坑会减速；落水或出界加罚一杆，并回到上一击球点。只有低速经过洞杯才算进洞，每洞最多计 12 杆。

手机断开、重新校准、切到后台、离开正式球局或进入练习室会取消正式击球准备，重新打开存档也从试挥开始。已用杆数显示真正完成的击球与罚杆数。

当前局自动保存在 .local/game.json；刷新页面或重启本地服务后可恢复。原始传感器数据、校准、挥杆日志均不发送到公网。

## 多人同场与独立手机

大厅选择“多人对战”，在“参赛人数”中选择 **2、3、4，或更多人数（上限 16）**，再勾选相同数量的已连接手机。每台手机显示独立编号、姓名和装扮；在手机“姓名与装扮”中修改。人数不足或勾选数量不符会提示补齐，其他连接手机可旁观，下一局再加入。

- 每次实际击球后轮换，当前球手显示在名单首位；球位、杆数、罚杆和计分卡分别保存。全部球手完成本洞后进入下一洞，已完成者自动跳过。
- 只有当前绑定手机能准备、挥杆和转动人物视角。未轮到的手机显示等待；多人正式球局不接受电脑代打。电脑可调整瞄准和取消准备。
- 手机断线会取消准备并保留球手位置；相同浏览器重连恢复身份。同一手机重复打开页面时，最新页面接管，旧页面停止连接。
- 练习室在“当前训练手机”选择球手，单独查看校准进度、归零、引导校准、调灵敏度和训练历史。切换手机会撤销准备，清除上一台手机尚未应用的参数草稿。
- 手机身份与灵敏度存于手机浏览器；换浏览器、清除网站数据或改变访问地址，会被视为新手机。电脑保存 .local/players.json、practice.json、game.json；新局开始时把旧局归档到 rounds.json（最近 20 局）。计分卡可导出当前局和归档逐杆记录，包含球手、实际输入手机、角速度、力量、方向及当时参数。

## 有反馈的引导校准

点击手机“启用体感”，或在练习室选择手机后点击“引导校准”。手机逐步展示动画、动作说明、识别结果和重试原因：

1. **握姿归零**：自然横握并静止约 1.1 秒，进度条自动完成；移动时说明原因并重新计时。
2. **自动找方向**：点击开始，缓慢上杆，再沿原路下挥、停稳；分析三轴响应。混合多个方向时明确提示稳定手腕。
3. **建立力度范围**：分别采样一次轻挥与一次舒适的大幅挥杆，不要求全力甩动。两次太接近不会保存，允许重做。
4. **中等力度复测**：目标 50%，连续两次进入 35%–65% 的目标带，且相差不超过 15 个百分点；握姿明显偏转时提示先归位。会显示具体百分比及增减挥幅建议。
5. **确认使用**：复测通过后才出现“使用这组校准”。想保留力度只重置方向，可用“握姿归零”；灵敏度仍可手动调节。

参考任天堂官方的握姿重置、试挥、力量条与地图标记逻辑，也针对其推杆预判较困难的部分，在所有训练球杆上保留统一力量刻度及模拟落点。新增的分步采样、自动找轴和重复性复测是本项目设计，尚不能声称真实手感优于任天堂。来源：[Nintendo Switch Sports 官方操作指南](https://www.nintendo.com/jp/ichikara/as8sa/index_en.html)。

## 首次连接 iPhone

iPhone 与电脑必须连接同一无线网络。手机体感需要受信任的 HTTPS；电脑可继续使用 localhost HTTP。

1. Windows 双击 **配置手机连接.cmd**；Mac 双击 **配置手机连接.command**。源代码版也可执行 npm run setup:https。
2. 工具为当前局域网地址生成证书。Mac 使用自带证书工具；Windows 如缺少 OpenSSL，请先安装或用 OPENSSL_PATH 指定位置。
3. 重启游戏，在电脑上点击“连接手机”，展开“第一次用 iPhone？”。
4. 在 iPhone 上打开面板中的证书下载链接，在“设置 → 通用 → VPN 与设备管理”安装描述文件。
5. 在“设置 → 通用 → 关于本机 → 证书信任设置”启用 **挥杆之间 本地证书**。升级自旧版时，保留的旧证书名称可能是 SwingLink Local Development CA。
6. 再次扫码，点击“启用体感”并允许访问。横握手机，保持静止约一秒，按分步提示完成方向识别、轻挥与舒适大幅采样，再做两次中等力度复测。

根证书不会自动安装或信任。请保管 certs 文件夹内的私钥，不要把该文件夹发送给别人。局域网地址变化后重新配置并重启；同一台电脑的根证书会保留。服务器证书有效期一年。

如果连接失败，检查家庭网络的防火墙、访客网络或无线设备隔离。每次服务重启会更新配对令牌，请扫描最新二维码。游玩时保持手机页面在前台并握紧手机，周围应留有足够空间。

## 挥杆练习室

0.4.0 将练习室改为第三人称 3D 训练场。原创球手站在发球点，可选择“青苔”“海盐”“落日”四套装扮。人物会做上杆、下挥和收杆动作，手机实时动作也会驱动人物姿态。电脑打开练习室后，手机自动进入练习模式；离开所有练习室后恢复原模式。

1. **试挥找力度**：初始为试挥模式。手机挥动或点击“试挥一次”，人物挥杆但球留在原位；力量条、小地图和金色标记显示模拟参考。试挥不进入成绩记录。
2. **瞄准与准备**：选择球杆、目标距离，调整左右瞄准；需要观察线路时切换“球道俯视”。点击电脑或手机上的“准备击球”，只启用下一次有效挥杆。
3. **击球与追球**：挥动手机，或用电脑力度按钮 / 空格蓄力后松开。人物击球后镜头跟球、展示落点，再自动回到站位。该杆完成后自动恢复试挥模式。
4. **根据结果调整**：比较飞行、滚动、偏左偏右、打长打短和距目标距离。每次只改一项灵敏度，再连续打三杆比较。

- **镜头与球手**：第三人称站位、球道俯视、自动追球和回到站位；四套装扮保存在本机浏览器。球道平坦、无风，供同条件比较。可选一号木杆、7 号铁杆、挖起杆、推杆，目标为 5–280 米，左右瞄准为 ±35°。
- **左右实时信息**：左侧力量条、上次力度线、三轴角速度，右侧目标地图、角速度峰值、上杆 / 下挥节奏和握姿偏转。地图中 25%、50%、75%、100% 标记由同一球杆物理模型计算。
- **传感器与调参**：点击同名按钮展开完整三轴曲线及手动灵敏度。力量倍率、方向倍率、上杆阈值、力量曲线均须收到手机回执后才显示生效，参数保存在手机。无手机也可直接使用电脑试挥和击球。
- **每杆反馈**：总距离、飞行距离、落地后移动、最高点、模拟出球速度、左右与前后偏差、距目标距离；手机还显示角速度峰值、上杆 / 下挥时长和节奏比。
- **训练记录**：服务器按手机独立保存最近 50 次实际击球，可回看和导出中文 JSON，含瞄准角度及手机参数。刷新或重启服务均可恢复。训练不改变正式球局球位和杆数。

手机断开、重新校准、切到后台或离开训练场会取消准备。运动期间不能再次击球。原始传感器在正式球局或练习室打开时按约 12 次/秒转发，超过 1.8 秒无数据显示暂停，不写入服务器磁盘。

距离、球速与弹道为游戏模拟，人物与球杆动作是示意；手机无法测量真实杆面、触球位置或旋转。节奏比只用于相同识别阈值下的多次比较。本版交互参考了 [Nintendo Switch Sports 官方高尔夫指南](https://www.nintendo.com/jp/topics/article/9183c639-08d7-4520-a444-26f9b0bce889)，人物和场景均为项目原创。

手机“挥杆诊断”同样可查看和调整参数。引导流程自动选择响应最清楚的感应轴；手动改轴后需重新校准。再次打开手机时，可使用已保存的力量校准；方向零点仍会重新测量。识别过程为“静止 → 上杆 → 下挥 → 击球 → 冷却”。

最近 50 次挥杆保存在手机，可标记“偏轻”“偏重”“误触发”或“漏识别”。JSON 与 CSV 的导出字段、状态、手感记录均为中文，CSV 使用带签名的 UTF-8 编码以方便表格软件打开。

真实设备验收仍需完成：20 次正常挥杆各触发一次；10 次拿起、放下或轻抖无误触；轻、中、重各 10 次能区分；检查左右方向、轻推、锁屏、切后台和断网。自动化测试不能证明真实挥杆手感已经达标。

## 开发和测试

```powershell
npm run dev
npm test
npm run test:integration
npm run test:multiplayer
```

集成测试需要先配置证书。测试分别使用独立的 5197/8497 和 5198/8498 端口和测试存档目录，不影响当前球局。Mac 发布包只内置 Node 可执行文件，不含 npm；开发请安装完整 Node.js，或直接用 runtime/node 执行测试脚本。

| 目录 | 用途 |
| --- | --- |
| local-gateway | 本地页面服务、HTTPS、配对、消息和存档 |
| game-service | 权威物理、处罚、计分和球洞推进 |
| shared | 球场地形、纯规则、挥杆识别、中文导出 |
| screen-web | 三维场景、镜头、路线图与电脑操作 |
| phone-web | 手机权限、校准、体感输入与日志 |
| scripts | 启动、证书配置与 Mac 打包工具 |
| tests | 规则和本地连接测试 |
| docs | 原始需求、实现说明和素材来源 |

默认端口为 HTTP 5173、HTTPS 8443，可通过 PORT、HTTPS_PORT 调整。服务接受局域网连接，WebSocket 需要配对令牌及匹配的来源。服务器负责最终球位、版本顺序、重复输入检查和球运动期间的锁定。收到消息的确认不等于该挥杆已计入杆数。

## Mac 包的重新生成

从 [Node.js 官方发布目录](https://nodejs.org/dist/v22.23.4/)下载两个 darwin 架构的压缩包及 SHASUMS256.txt，放入 .local/mac-runtime，然后执行 python scripts/package-mac.py。脚本只打包白名单文件，保留 Mac 可执行权限，并拒绝混入 Windows 专用依赖。

当前版本没有远程双人、公网房间或跨洋联机。三维植被和场景使用本项目原创的程序化模型；依赖来源和许可证见 docs/ASSETS.md。完整验证情况见 docs/IMPLEMENTATION.md。


## 0.10.0 果岭与推杆

点击“查看果岭坡度”显示贴合地形的读线网格和下坡流动箭头；颜色越暖、流动越快代表坡度越大。推杆提示显示上坡/下坡、侧向借位、球洞高差和滚动中的球速，手机选杆区同步提示。果岭草面增加细密剪草纹理。

推杆会受坡度与地面阻力共同影响；洞缘接触区分擦边、绕洞弹出、绕洞落杯和高速越洞。洞缘动画保留观察时间，落杯包含下落、杯底轻弹与音效，中文逐杆记录保存反馈。参数用于游戏体验，并非真实球场测量。

顶栏“♫ 音乐 开／关”显示播放状态，点击后仅提供播放／暂停和音量。0.13.0 已替换为用户更新的 Brian Crain — Butterfly Waltz，文件位于 screen-web/assets/music/butterfly-waltz.mp3。无需联网或手动导入，默认音量 25%；首次操作页面后开始循环播放。若浏览器阻止自动播放，可点击“♫ 音乐”→“播放音乐”。暂停和音量会记忆，切换球场或练习室不会中断播放；旧版浏览器自选音频不再覆盖内置曲目。

旁边的扬声器按钮控制风声、鸟鸣与击球音效。音乐独立控制；开启球场音效时，实际击球、撞树和落杯会让音乐及环境音自动减弱，球停稳后平滑恢复。用户音量滑块保持不变，暂停后的音乐保持暂停。页面切到后台时，风声与鸟鸣淡出。

更新后重新启动游戏并刷新电脑和手机页面。Mac 双架构包同样包含上述功能，未进行 Mac / iPhone 真机验证。
